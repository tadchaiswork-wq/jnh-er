โมดูล ER — HTML Mockup

หน้าจอจำลองของโมดูล ER (opd-er-*.php) ในระบบ KPHIS เดิม ทำเป็น HTML ล้วน เปิดดูได้โดยไม่ต้องมีเซิร์ฟเวอร์/ฐานข้อมูล · ข้อมูลผู้ป่วยทั้งหมดเป็น ข้อมูลสมมติ · ปุ่มบันทึก/ยืนยัน/ลบ จะแสดงข้อความแจ้งเท่านั้น ไม่มีการบันทึกจริง · ต้องต่ออินเทอร์เน็ต (โหลด jQuery / Bootstrap JS / Font Awesome / DataTables / Chart.js จาก CDN)

ส่วนที่ 1 · Triage ใหม่
หน้า Triage — สแกน Visit, V/S, GCS, Trauma body map, NEWS2/SIRS, แนะนำระดับ, Fast track
ส่วนที่ 2 · กระดานผู้ป่วย ER ใหม่
กระดานผู้ป่วย ER (แพทย์) — นับเคสตามระดับ, เรียง R→N, แจ้งเตือน Fast track กระดานผู้ป่วย ER (พยาบาล) — Order ที่ยังไม่รับกระพริบ, จัดเตียง
ส่วนที่ 3 · บันทึกการรักษา ใหม่
บันทึกการรักษา (แพทย์) — One day order, Progress note + สรุป triage, Standing order, สรุป PH/CC/PI/PE/Dx/Mx/Plan, D/C / Admit บันทึกการรักษา (พยาบาล) — รับ order → Nurse note, Nurse note timeline, จำหน่าย / ใบนำส่ง
