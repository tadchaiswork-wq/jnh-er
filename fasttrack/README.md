# ER Fast Track Web App

ระบบ countdown timer สำหรับห้องฉุกเฉิน - Stroke, STEMI, Sepsis

## เริ่มต้นใช้งาน

1. อ่าน **SETUP.md** เพื่อตั้งค่า Firebase
2. แก้ไข **config.js** ใส่ Firebase config ของคุณ
3. ทดลองใช้: `python3 -m http.server 8000` แล้วเปิด http://localhost:8000

## ไฟล์ในโปรเจค

| ไฟล์ | คำอธิบาย |
|------|---------|
| `index.html` | หน้าเลือกโหมด |
| `entry.html` | หน้าลงข้อมูลเคส |
| `tv.html` | หน้าแสดงผลบนทีวี |
| `config.js` | Firebase config (ต้องแก้) |
| `SETUP.md` | คู่มือติดตั้งฉบับเต็ม |

## เวลาเป้าหมาย

- STROKE: 60 นาที
- STEMI: 30 นาที
- SEPSIS: 60 นาที

## คุณสมบัติ

- ลงข้อมูลข้ามอุปกรณ์ ซิงค์ทันทีผ่าน Firebase
- กระพริบ + เสียงแจ้งเตือนเมื่อเหลือ 10 นาที
- แสดงผลต่อ 20 นาทีหลังหมดเวลา
- ไม่มีข้อมูลผู้ป่วยที่ระบุตัวตน (เก็บแค่เลขเตียง)
